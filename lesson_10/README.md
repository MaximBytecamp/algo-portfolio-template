## Задача 1. Пара с суммой (модуль 8)

```python
def pair_sum(nums, target):
    left, right = 0, len(nums) - 1
    while left < right:
        s = nums[left] + nums[right]
        if s == target:
            return left, right
        if s > target:
            right -= 1
        else:
            left += 1
    return None
```

Вход: `nums = [1, 3, 4, 6, 8, 11]`, `target = 10`.

**На листе:** выпишите массив в клетки с индексами. Под ним стрелками
отметьте `left` и `right` на каждом шаге: одна строка — один шаг.

## Задача 2. Самая длинная подстрока без повторов (модуль 10)

```python
def longest_unique(s):
    window = set()
    left = 0
    best = 0
    for right, ch in enumerate(s):
        while ch in window:
            window.remove(s[left])
            left += 1
        window.add(ch)
        best = max(best, right - left + 1)
    return best
```

Вход: `s = "abcbdeca"`.

**На листе:** выпишите строку в клетки. Для каждого `right` обведите
текущее окно рамкой, а буквы, которые убрал цикл `while`, зачеркните.

## Задача 3. Объединение интервалов (модуль 12)

```python
def merge(intervals):
    result = []
    for start, end in sorted(intervals):
        if result and start <= result[-1][1]:
            result[-1][1] = max(result[-1][1], end)
        else:
            result.append([start, end])
    return result
```

Вход: `[[8, 10], [1, 3], [15, 18], [2, 6], [9, 12], [18, 20]]`.

**На листе:** нарисуйте числовую прямую от 0 до 20. Над ней — исходные
интервалы отрезками, под ней — ответ.

## Задача 4. LRU и FIFO (модуль 20)

Кэш на 3 места. Последовательность запросов:

```text
put a 1, put b 2, put c 3, get a, put d 4, get b, get c, put e 5, get a, get d
```

`get` возвращает значение или `-1`, если ключа нет. LRU вытесняет ключ,
к которому дольше всех не обращались. FIFO вытесняет ключ, который
дольше всех лежит в кэше, и порядок при `get` не меняет. Пройдите
последовательность два раза: с LRU и с FIFO.
