# Задание 3 · Замеры времени выполнения и использования памяти

Третья папка курса: занятие 2 идёт без домашней работы, поэтому папка третья,
а занятие четвёртое.

Материал к работе:
[презентация занятия](https://algorthimization-course-vvodnoe.vercel.app/op04-algoritmizaciya/lessons/04-zamery-vremeni-i-pamyati/index.html#slide-1)

## Что необходимо сделать

1. Изучить презентацию по теме занятия.
2. Запустить у себя программы и примеры, представленные в презентации.
3. Сделать скриншоты результатов выполнения программ. На скриншотах должны
   быть видны код программы, результат запуска и полученные значения времени
   выполнения и (или) использования памяти.
4. Создать отдельный `.md`-файл с отчётом по домашней работе.
5. Для каждого выполненного примера добавить в отчёт скриншот, короткое
   пояснение того, что измерялось, полученный результат и вывод
   на одно-три предложения.
6. Загрузить работу в свой репозиторий по дисциплине, в эту папку `lesson_03`.
7. Прислать преподавателю ссылку на папку с выполненной работой на GitHub.

Использовать ИИ допустимо: объяснить результаты, сформулировать выводы,
оформить Markdown, разобрать непонятный участок кода. Программы при этом
нужно запустить самому и получить собственные результаты.

## Что должно быть в папке

- `.md`-файл с отчётом: можно взять готовый бланк `homework_03.md`;
- скриншоты, папка `screens/` рядом с отчётом;
- при необходимости файлы с исходным кодом.

## Работа считается выполненной, если

- примеры из презентации запущены;
- результаты подтверждены скриншотами;
- скриншоты оформлены в `.md`-файле;
- к каждому примеру написан короткий вывод;
- работа загружена в папку `lesson_03` на GitHub;
- прислана ссылка на выполненную работу.

## Где взять программы

Все примеры презентации собраны в архиве:
[algorithm_measurements.zip](https://algorthimization-course-vvodnoe.vercel.app/op04-algoritmizaciya/lessons/04-zamery-vremeni-i-pamyati/algorithm_measurements.zip).
Распаковывайте целиком: файл `measurements.py` нужен соседним скриптам.

Запускаются одиннадцать файлов: `02_first_measurement.py`,
`03_growth_experiment.py`, `04_constant_access.py`, `05_linear_search.py`,
`06_quadratic.py`, `07_list_vs_set.py`, `10_final_experiment.py`,
`11_sum_comparison.py`, `12_memory_comparison.py`, `13_list_generator.py`,
`14_repeated_runs.py`. Файлы `01`, `08` и `09` задают функции и сами ничего
не печатают.

Команда запуска: `python3 02_first_measurement.py`, на Windows —
`py 02_first_measurement.py`. Нужен Python 3.10 или новее.

Числа у всех будут разные: они зависят от компьютера и от того, что на нём
ещё запущено. Эталонных секунд не существует, поэтому я сравниваю не с чужими
значениями, а ваши числа между собой.

## Как сдать

Работа уходит в ветку `hw-03` и дальше через Pull Request в вашу `main`.
Всё делается кнопками в VS Code: [ветки](../docs/git/README.md#5-ветки) ·
[коммиты](../docs/git/README.md#3-изменения-и-коммиты) ·
[публикация ветки и Pull Request](../docs/git/README.md#6-ветки-на-github-и-pull-request).
После слияния пришлите ссылку на папку `lesson_03` в своём репозитории.

## Если не получается

| Что видите | Что делать |
|---|---|
| `ModuleNotFoundError: measurements` | запускаете не из папки `algorithm_measurements` или потеряли файл `measurements.py` |
| `python3: command not found` | на Windows команда называется `py` |
| Время выводится как `0.000000` | это очень быстрая операция: возьмите `14_repeated_runs.py` и смотрите на серию повторов |
| Числа скачут от запуска к запуску | так и должно быть: запустите несколько раз и возьмите медиану, об этом экран 9 презентации |
| Память подписана как MB | это MiB, деление идёт на 1024² |
