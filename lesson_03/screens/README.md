# Скриншоты домашней работы № 3

Сюда положите кадры запусков в формате PNG, по одному на каждый пример:
`01-primer.png`, `02-primer.png` и дальше по порядку. Можно называть
по имени скрипта, например `02-first-measurement.png`, тогда поправьте
ссылки в бланке.

На каждом кадре должно быть видно три вещи: код программы, команду запуска
и вывод с числами времени или памяти.
