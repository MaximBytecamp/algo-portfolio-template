# algo-portfolio · ОП.04 «Основы алгоритмизации и программирования»

Ваш репозиторий на всю дисциплину: решения задач, тесты к ним и заметки о том,
сколько решение стоит по времени и памяти. К концу курса это и есть портфолио,
которое можно показать на собеседовании.

## С чего начать

**1. Сделайте репозиторий своим.** Нажмите **Use this template → Create
a new repository** и назовите его `algo-portfolio`. Кнопка **Fork** для этого
не подходит: форк остаётся привязан к исходному репозиторию.

**2. Поставьте Python и git.** Нужен **Python 3.12**, на Windows при установке
отметьте галочку *Add Python to PATH*.

```bash
git clone <адрес вашего репозитория> algo-portfolio
cd algo-portfolio
```

**3. Соберите окружение.** Команды различаются по системам:

| Шаг | macOS / Linux | Windows (PowerShell) |
|---|---|---|
| создать окружение | `python3 -m venv .venv` | `py -m venv .venv` |
| активировать | `source .venv/bin/activate` | `.venv\Scripts\Activate.ps1` |
| поставить pytest | `pip install -r requirements.txt` | то же |
| проверить | `pytest --version` | то же |

Если последняя команда напечатала версию pytest, всё готово. Активировать
окружение нужно перед каждой работой: в начале строки появится `(.venv)`.

*Если PowerShell не даёт запустить `Activate.ps1`, один раз выполните
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`. В cmd активация —
`.venv\Scripts\activate.bat`.*

## Домашние работы

| Папка | Занятие | Что сдаёте | Ветка |
|---|---|---|---|
| `lesson_01` | 1 · алгоритмы вокруг нас | `homework_01.md`, кода нет | `hw-01` |
| `lesson_02` | 3 · сложность и O-нотация | `answers.py`, `limits.md`, `acceptance.md` | `hw-02` |
| `lesson_03` | 4 · замеры времени и памяти | `homework_03.md` и скриншоты запусков | `hw-03` |

Занятие 2 идёт без домашней работы, поэтому нумерация папок и нумерация
занятий расходятся.

Что именно делать, написано в `README.md` внутри папки занятия. Там же лежат
бланки: вы вписываете свои ответы в готовую разметку, а не сочиняете файл
с нуля. Задачу занятия я выдаю на паре, её файлы кладите в ту же папку.

Папку для следующего занятия делаете копией предыдущей:
`cp -r lesson_03 lesson_04` (на Windows —
`Copy-Item -Recurse lesson_03 lesson_04`).

## Как сдавать

Одно задание — одна ветка — один Pull Request.

```bash
git switch -c hw-03          # ветка на задание, номер по папке
pytest lesson_02             # если в задании есть тесты
git add lesson_03
git commit -m "hw-03: замеры времени и памяти, шесть запусков"
git push -u origin hw-03
```

Дальше на GitHub открываете **Pull Request** в свою `main` и коротко пишете:
что за задача, какой подход выбрали, сколько он стоит по времени и памяти,
какие тесты добавили. Сдать нужно до начала следующего занятия.

Всё то же самое можно делать мышкой в VS Code, без терминала. Разбор
со скриншотами: [коротко](docs/git/README.md) — основные операции
с размеченными кадрами, [подробно](docs/git/FULL.md) — каждый шаг,
включая типичные ошибки.

## Правила

- На тренировке ИИ можно **после собственной попытки**: review, дополнительные
  тесты, оформление готовых мыслей в `.md`. Ответ проверяете запуском.
- На диагностике, mock-интервью, контестах и экзамене ИИ, поиск
  и автодополнение закрыты.
- В каждом задании отдельно написано, где модель разрешена, а где нет:
  смотрите `README.md` папки.
- Замеры, запуски и скриншоты вы делаете сами, на своём компьютере.
- Тесты должны запускаться у другого человека после `git clone`.
