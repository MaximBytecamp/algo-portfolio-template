В обеих задачах нет срезов и вызовов `sum` внутри цикла: сумма окна

## Задача 1. Очки фитнес-браслета

LeetCode 1176 · Diet Plan Performance. Задача на LeetCode платная, условие
целиком приведено здесь.

`steps[i]` — число шагов за день `i`. Браслет оценивает каждые `k` дней подряд:

- сумма шагов меньше `lower` — минус одно очко;
- больше `upper` — плюс одно очко;
- от `lower` до `upper` включительно — ноль.

Нужно вернуть сумму очков по всем окнам.

| Вход | Ответ | Почему |
|---|---|---|
| `[1, 2, 3, 4, 5]`, `k = 1`, `lower = upper = 3` | `0` | −1, −1, 0, +1, +1 |
| `[3, 2]`, `k = 2`, `lower = 0`, `upper = 1` | `1` | одно окно, сумма 5 |
| `[6, 5, 0, 0]`, `k = 2`, `lower = 1`, `upper = 5` | `0` | суммы 11, 5, 0: +1, 0, −1 |

- `1 <= k <= len(steps)`, иначе `ValueError`. `lower > upper` — `ValueError`.
- Список `steps` не меняется.
- Время O(n). Тест даёт 200 000 дней, окно 100 000 и 2 секунды.

## Задача 2. Кодовый замок

LeetCode 1652 · Defuse the Bomb.

Числа кода `code` записаны по кругу: после последнего снова идёт первое.
Каждое число заменяется одновременно со всеми остальными:

- `k > 0` — суммой `k` следующих чисел;
- `k < 0` — суммой `|k|` предыдущих чисел;
- `k == 0` — нулём.

| Вход | Ответ | Почему |
|---|---|---|
| `[5, 7, 1, 4]`, `k = 3` | `[12, 10, 16, 13]` | для 5: 7 + 1 + 4; для 7: 1 + 4 + 5 |
| `[1, 2, 3, 4]`, `k = 0` | `[0, 0, 0, 0]` | |
| `[2, 4, 9, 3]`, `k = -2` | `[12, 5, 6, 13]` | для 2: 3 + 9; для 4: 2 + 3 |

- Пустой `code` — `ValueError`. `|k| >= len(code)` — `ValueError`.
- Возвращается новый список, `code` не меняется.
- Время O(n), память O(1) кроме ответа. Тест даёт 200 000 чисел,
  `k = 100 000` и `k = −100 000`, по 2 секунды на каждый запуск.

Подсказка: окно для позиции `i` — это отрезок соседей, и при переходе
к `i + 1` он сдвигается на одну позицию. Индекс по кругу — остаток от деления
на `len(code)`.
